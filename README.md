# Book 3 AI and Weapons

This Unity project contains the completed tutorials for **Adding Simple AI** and **Creating and Managing Weapons**.

## Play the Game

[Click here to play the WebGL version](https://ajh767676.github.io/Book3_AI_Weapons/WebGL/)

## Scenes

- **simple_ai** — Adjust projectile intensity, spawn interval, and the number of objects needed to advance.
- **training_camp** — Practice shooting, reloading, changing ammunition settings, managing health, and throwing grenades.

## Controls

- **P** — Pause or resume
- **Mouse** — Look around
- **Left Mouse Button** — Shoot
- **R** — Reload
- Use the on-screen controls for additional options.
